# AI Update Prompt Examples

Use these prompt examples with any AI coding assistant to safely update the portfolio content.

## Add a certificate

“Add my new certificate to the portfolio. The PDF is named example.pdf, the issuer is Example Academy, the issue date is July 2026, and it should be a supporting certificate. Do not change the website design. Update only the relevant JSON and asset path, then run npm run verify.”

## Feature a certificate

“Find the 'web-red-team-analyst' certificate in content/certificates.json and set it to featured. Re-verify the changes.”

## Replace a certificate PDF

“Replace the PDF path for 'web-red-team-analyst' with '/assets/certificates/new-web-rta.pdf'. Ensure the file exists and run npm run verify.”

## Add experience

“Add a new cybersecurity internship to content/experience.json. Preserve the current design and ordering. Update Shehzada’s AI automatically through shared content and run npm run verify.”

## Add a project

“Add my new project 'Network Scanner' to content/projects.json. It uses Python and Docker. Generate a safe ID and slug. Do not touch the website design. Verify everything after updating.”

## Update a project

“Update the summary for the 'Network Scanner' project in content/projects.json to highlight the newly added async scanning capabilities.”

## Add a skill

“Add 'Cloud Security' to content/skills.json. Pick an unused keyboard position and assign a relevant icon. Verify the layout isn't broken.”

## Add an achievement

“Add a new achievement 'Top 10 HackerOne' to content/achievements.json. Set isBadge appropriately depending on if it should be rendered as a badge. Verify the changes.”

## Update profile

“Update my email address in content/profile.json to mynewemail@example.com.”

## Update contact links

“Update my GitHub URL in content/profile.json to point to my new handle.”

## Update SEO

“Improve the SEO description naturally for Abdullah Cyber and cybersecurity in Pakistan. Do not keyword-stuff or change the design. Update only content/seo.json and run npm run verify.”

## Update AI greeting

“Change the greeting in content/ai.json to sound more formal, but keep the recruiter and evidence scan capabilities intact.”
