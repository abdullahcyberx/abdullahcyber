# TinaCloud Setup Guide

1. Create a project in [TinaCloud](https://app.tina.io/).
2. Connect it to your GitHub repository (`abdullahcyberx/abdullahcyber`).
3. Set the Site URL to `https://abdullahcyber.dev`.
4. Ensure the branch is set to `feature/tinacms-secure-admin` or `main`.
5. Invite your editor email.
6. Generate a Token and copy the Client ID.
7. Set these in Cloudflare Pages as `TINA_TOKEN` and `NEXT_PUBLIC_TINA_CLIENT_ID`.
