# Security Policy

## Supported Versions

Only the latest deployment on the `main` branch is supported with security updates.

## Reporting a Vulnerability

Please report any security vulnerabilities via email to `abdullahcyberx@gmail.com`.
Include a brief description, steps to reproduce, and any relevant proof of concept.
You should receive a response within 48 hours.

Please do not open a public issue for security vulnerabilities.
